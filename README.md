# TextChat Server

Fixed Render-ready ASP.NET Core 8 text-chat backend.

The server uses:
- SQLite
- BCrypt.Net-Next
- Multiple chat servers
- Accounts
- Login/logout
- Messages
- Member lists
- Admin kick/ban
- Render Docker deployment

WinForms client base URL:

https://textchatfixed.onrender.com

For Render, set:
ACCOUNT_ADMIN_USER
ACCOUNT_ADMIN_PASSWORD
